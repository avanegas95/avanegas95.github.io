### What it does

Paychira is a sales-forecasting tool for small agencies. Anderson used AI tools to design, build and deploy it. It tracks deals and turns them into revenue forecasts, so agencies can see what the pipeline is likely to bring in.

### Highlights

- Leveraged AI tools to design, build, and deploy a sales-forecasting tool for small agencies: features a deal pipeline, probability-weighted revenue forecasts, org/team roles, CSV import, PandaDoc contract synchronization, and AI chat, on the pipeline data.
- Front end: React 18, Vite, Tailwind (Hosted on Vercel); Backend: FastAPI, Pydantic REST API (Hosted on Render); Database: Supabase
- Automated PR process; Implemented Gemini Code Review and CodeRabbit in the repository to provide feedback and improve code quality. Pulled deployment status from Vercel and Render as checks to confirm success status, before merging.
