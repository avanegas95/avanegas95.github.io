### What does HIL (Hardware-in-the-Loop) mean?

Hardware-in-the-Loop testing runs software against the real hardware, so a robot actually moves instead of a simulation pretending. At Boston Dynamics, Anderson owns triage for nightly HIL robot runs: he investigates failures, writes high-level root-cause summaries, routes hardware issues to the right teams, and implements hotfixes when failures trace to his team's code or to software changes.

### What is Gazebo?

Gazebo is a robot simulator that lets teams try things in a virtual world before touching a real machine. Anderson used Gazebo simulation worlds to create and develop test cases that were later run on real hardware.

### What is Appium?

Appium is a tool that taps, swipes and types in a mobile app the way a person would, so UI tests can run on their own. Anderson introduced Appium automation on emulated Android tablets at Boston Dynamics, and later grew that suite from 16 to 33 automated tests.

### What is Pytest?

Pytest is a popular Python testing framework for writing and running automated tests. Anderson built a Python monitoring tool that collects onboard robot metrics over SSH and works on its own or as a Pytest fixture.

### What are Smoke, Sanity and Regression tests?

In general, a Smoke test is a quick check that the basics work, a Sanity test is a focused check that a recent change behaves, and a Regression test is a broad sweep that nothing old broke. Anderson led the reorganization of a 700+ test case library into these three tiers, defining clear criteria for each, with a goal of cutting the regression cycle from 3 months to 1 month.

### What is Blob not?

Blob is not Anderson, and it does not speak for him in the first person. It cannot write code or do homework, and it will not guess dates, salary, availability or visa status. When something is not in the knowledge base, Blob says so and points to Anderson's email or LinkedIn.

### Does Blob remember or store my questions?

Blob does not log the text of your questions, and the chat can be cleared. Within one chat, Blob does use your earlier messages to follow the conversation. The site only keeps aggregate numbers such as how many questions were asked, how fast replies were, and error counts.
