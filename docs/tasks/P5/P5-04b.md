## Behaviour / rules
1. Idle: greeting bubble "Hi! I'm Blob 👋 Ask me anything about Anderson." + 3–4 starter chips; input directly under Blob, always visible (no "open" step).
2. On send: the question shows briefly above the bubble; the bubble streams the latest answer in full, sized to content up to a max height (`min(60vh, 28rem)`), then "Show more" expands in place; no inner scroll log.
3. Earlier turns sit behind a "Previous" control (button with `aria-expanded`) that reveals them in a list; at most the last 10 turns kept (unchanged history caps).
4. ≤ 640 px: bubble is full width below Blob. ≥ 641 px: bubble beside or below Blob depending on container width (container query, so any placement works).
5. a11y: bubble region `aria-live="polite"` (answer text only, no mood announcements); input has a visible label; `Esc` clears focus back to the input and stops nothing (stream keeps running, decision 2026-10-14); "Clear chat" and the AI disclaimer stay under the input. No focus trap (it's no longer a modal).
6. Reserve the bubble's min height so the first token causes no shift; growth goes downward only.
7. Reduced motion: no bubble pop animation.
