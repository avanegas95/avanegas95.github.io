## Interfaces

- `[slug].astro` uses `getStaticPaths()` over `getPublicProjects()`, prerendered (`output: "static"`). Slug = KB file name without `.md`.

## Behaviour / rules
1. One KB file per landed card. Facts go in frontmatter (`title`, `status`, `tech`, `links`, `cover`, `featured`, `order`), taken from `src/data/projects.ts` as Anderson left it.
2. `summary` comes **verbatim** from that card's `description` in `projects.ts`. Paychira, Orbit Hop and State of Ecosystems already exist in the KB: add card frontmatter and keep their bodies. A card with no KB body yet (AI Digest, avanegas.com) gets `public: false` and its card description as the body, verbatim. It doesn't show on the site or in the prompt. List those files in the report for Anderson.
3. Cards: the title links to `/projects/<slug>/`, and repo and live links stay as they are. Cards without `cover` use an image-less variant, never the placeholder image. Links get the same tracking-param rule as P5.5-03.
4. Detail page: title, status, tech, links, then the KB body rendered as markdown, then the gallery when present. Images go through `astro:assets` (AVIF/WebP, explicit width/height, lazy below the fold). There's a back link to `/#projects`. Meta: `<title>` = KB `title`, description = KB `summary`, canonical URL, og:image = `cover` or the site default.
5. Status and link consistency: `status: "in development"` → no `live` link. `links.repo` shows only when Anderson marked the repo public.
6. Screenshots are added by Anderson only: image files in the folder, plus a `gallery` entry with his alt text. Never write alt text, and never invent a gallery entry for an unlisted image.
7. The KB token budget stays ≤ 15k (`kb-budget`). Detail pages show the same body Blob reads, so long write-ups cost prompt tokens. If the files push over, stop and report the numbers.
8. Blob's reply-scrubber allowlist is **not** changed (security-sensitive; a follow-up if Anderson wants Blob to link project pages).
9. CI `voice:check` fails on this branch until Anderson runs `voice:accept`. That is the human gate, so don't work around it.
