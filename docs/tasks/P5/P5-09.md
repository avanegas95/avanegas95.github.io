## Behaviour / rules
1. RUNBOOK is **public-safe**: env var names only, no values, project/team/DB IDs, URLs of Previews, dashboards with IDs, or security findings. Use placeholders like `<preview-url>`.
2. Sections: what runs where; turning Blob off fast (set `DAILY_BUDGET_USD=0`, redeploy; confirm from `budget.ts` and its tests that 0 blocks every request, and document what it actually does) and back on; changing `CHAT_MODEL`/`CHAT_EFFORT`; rotating `ANTHROPIC_API_KEY` and `IP_HASH_SALT`; reading logs (metrics only); rate-limit and budget responses; spend alert and the Anthropic workspace cap; running evals (local, `--spend`, $1 guard); what not to do before P6 (DNS, CNAME, Pages workflow).
3. `check-headers.mjs <url>`: `HEAD /`, `/api/chat` (expects 405 on HEAD/GET), and the BotID path; asserts CSP, HSTS, `X-Content-Type-Options`, `Referrer-Policy`, `Permissions-Policy`, `X-Frame-Options` (`DENY`, `SAMEORIGIN` on the BotID path), `COOP`. Supports a protection-bypass header read from an env var, never printed.
4. `chat-smoke.js` sends one question to a given URL only with an explicit `--spend` flag; never in CI.
